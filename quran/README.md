# القرآن الكريم — نص كامل (رسم عثماني)

نص القرآن الكريم كاملاً (114 سورة، 6236 آية) برسم المصحف العثماني مع الضبط بالشكل.

## الملفات

| الملف | الوصف |
|------|-------|
| `quran.json` | القرآن كاملاً في ملف JSON واحد (السور والآيات منظّمة) |
| `quran.txt` | القرآن كاملاً كنص قابل للقراءة المباشرة |
| `surahs/1.json` … `surahs/114.json` | كل سورة في ملف JSON مستقل |

## بنية `quran.json`

```json
{
  "name": "القرآن الكريم",
  "script": "رسم عثماني (Uthmani)",
  "total_surahs": 114,
  "total_verses": 6236,
  "surahs": [
    {
      "id": 1,
      "name": "الفاتحة",
      "transliteration": "Al-Fatihah",
      "type": "مكية",
      "total_verses": 7,
      "verses": [ { "id": 1, "text": "بِسۡمِ ٱللَّهِ ٱلرَّحۡمَٰنِ ٱلرَّحِيمِ" } ]
    }
  ]
}
```

## التحقق من الصحة

- إجمالي الآيات = **6236** (مطابق للعدد الرسمي المعتمد — رواية حفص).
- عدد آيات كل سورة مطابق للعدّ القياسي (مثال: النور 64، الفرقان 77).
- في `quran.txt` تُضاف البسملة في رأس كل سورة عدا سورة التوبة (9)، وسورة الفاتحة (1) لأن البسملة فيها آية مستقلة.

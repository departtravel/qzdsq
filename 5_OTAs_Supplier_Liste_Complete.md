# Toutes les OTAs où devenir supplier — Liste complète

*Recherche juin 2026. Commissions = fourchettes indicatives, négociées et confidentielles → à confirmer à l'inscription. Les sites bloquent l'extraction automatique : vérifier les chiffres en vous inscrivant.*

> ⚠️ **Le principe central :** ne vous inscrivez pas à la main partout. ## ❌ À ignorer / pièges
- **Aladia** : n'est PAS une plateforme de voyage (c'est de l'e-learning) — oubliez.
- **TourScanner** : metasearch, **pas d'inscription supplier** — on y apparaît automatiquement si on est sur Viator/GetYourGuide.
- **Ceetiz** : le programme public est de l'**affiliation** (revendre LE catalogue Ceetiz), pas du listing supplier → passer par leur équipe partenariats.
- **Airbnb Experiences / Headout / Withlocals / Tiqets** : inadaptés (voir tableau 1).

## ✅ Plan d'action OTAs (ordre conseillé)
1. **Ouvrir Bokun** (gratuit au départ) = votre hub.
2. **Brancher d'abord** : GetYourGuide + Viator + TUI Musement + Civitatis (vérifier le "1 fournisseur/activité") + **Google Things to Do** (0 %). → couvre aussi Booking.com/Expedia automatiquement.
3. **Multi-jours** : créer un profil **Bookmundi** (gratuit, accepte les TN) + postuler **TourRadar** + **Evaneos/TravelLocal**.
4. **Compléter** : Klook, Hellotickets, Trip.com (via Bokun), Much Better Adventures (aventure désert).
5. **Confirmer par email** l'acceptation Tunisie + la commission pour chaque plateforme avant de charger un gros catalogue.

> 💡 **Bon point :** votre marque **« Depart Travel Services / Djerba »** apparaît déjà comme supplier sur **GetYourGuide** et dans les résultats **TourRadar** — vous avez donc déjà un pied dans la place. Vérifiez/optimisez ces comptes existants en priorité.

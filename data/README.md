# مجموعة بيانات تحليلية للقرآن الكريم

بيانات منظّمة جاهزة لبرنامج يحلّل القرآن لغوياً ونحوياً وصرفياً ودلالياً وسياقياً.
كل الطبقات مفهرسة بالموقع القياسي `سورة:آية:كلمة:مقطع`.

## الملفات (في مجلد `data/`)

| الملف | المحتوى | الحجم |
|------|---------|------|
| `text.json` | النص بثلاث صور: عثماني (`uthmani`)، مجرّد من التشكيل (`plain`)، مطبّع للبحث (`normalized`) | ~3.3MB |
| `roots_index.json` | فهرس جذور الكلمات (1651 جذراً) مع عدد ومواضع كل ورود | ~0.8MB |
| `metadata.json` | بيانات وصفية: نوع السورة، مكان النزول، السجدات، عدّ الأجزاء/الصفحات | ~25KB |
| `tafsir_muyassar.json` | التفسير الميسّر لكل آية (6236) | ~2.9MB |
| `quran_full.json` | **الملف الرئيسي** — كل الطبقات مدموجة لكل آية | ~45MB |
| `build.py` | سكربت البناء (يعيد توليد كل ما سبق من المصادر الخام) | — |

> ملاحظة: `data/_raw/` يحوي المصادر الخام قبل المعالجة (الصرف، info)، ويمكن حذفه.

## مخطّط الآية في `quran_full.json`

```json
{
  "id": 2,
  "uthmani": "ٱلۡحَمۡدُ لِلَّهِ رَبِّ ٱلۡعَٰلَمِينَ",
  "plain": "ٱلحمد لله رب ٱلعلمين",
  "normalized": "الحمد لله رب العلمين",
  "juz": 1, "page": 1, "manzil": 1, "line": 2,
  "sajda": false,
  "tafsir_muyassar": "الثناء على الله بصفاته ...",
  "morphology": [
    { "n": 1, "segments": [
        { "form": "ٱلْ",   "pos": "P", "pos_ar": "حرف جر", "root": null,  "lemma": "ال",   "features": ["DET","PREF"], "tags": {} },
        { "form": "حَمْدُ", "pos": "N", "pos_ar": "اسم",     "root": "حمد", "lemma": "حَمْد", "features": ["M","NOM"],    "tags": {} }
    ]}
  ]
}
```

### حقول المقطع الصرفي (`segments[]`)
- `form`: صورة المقطع كما وردت.
- `pos` / `pos_ar`: نوع الكلمة (رمز Quranic Corpus + مقابله العربي).
- `root`: الجذر (ثلاثي/رباعي) — أساس البحث الدلالي والاشتقاقي.
- `lemma`: الأصل المعجمي (المدخل القاموسي).
- `features`: سمات نحوية/صرفية (`NOM` مرفوع، `ACC` منصوب، `GEN` مجرور، `M/F` تذكير/تأنيث، `S/D/P` مفرد/مثنى/جمع، `PREF` سابقة، `DET` تعريف...).
- `tags`: سمات قيمتها مفتاح=قيمة (مثل `MOOD`, `PERSON`).

## أمثلة استخدام تحليلية

- **بحث عن كلمة بصرف النظر عن التشكيل:** طابق على حقل `normalized`.
- **كل المواضع المشتقة من جذر:** `roots_index.json["roots"]["علم"]["occurrences"]`.
- **توزيع كلمة على الأجزاء/الصفحات/السور:** اجمع عبر `juz` / `page`.
- **التحليل النحوي للإعراب:** اقرأ `features` لكل مقطع (الحالة الإعرابية).
- **الفهم الدلالي/السياقي:** اربط `tafsir_muyassar` مع `metadata` (مكية/مدنية) لدراسة سياق النزول.

## التحقق
- 114 سورة، 6236 آية في كل الطبقات.
- التغطية الصرفية: 6236 آية كاملة.
- التفسير: 6236 آية كاملة.
- عدد الجذور: 1651.

## إعادة البناء
```bash
python3 data/build.py
```
يقرأ من `quran/surahs/`, `quran/tafsir_muyassar/`, و`data/_raw/` ويعيد توليد كل الملفات.

## توسعات مقترحة (لاحقاً عند الطلب)
- إضافة تفاسير أخرى (ابن كثير، السعدي، الطبري) — متاحة من نفس مصدر التفسير.
- طبقة معاني غريب القرآن.
- أسباب النزول.
- ترتيب النزول الزمني للسور (للتحليل التاريخي).
